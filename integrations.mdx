## Overview

Clarity OPS supports seamless integrations with popular third-party services. You can connect e-commerce platforms, accounting software, and custom applications using webhooks and the REST API. These integrations automate product syncing, inventory updates, and order processing, streamlining your operations.

<Callout kind="info">
  All integrations require an API key from your Clarity OPS dashboard. Generate one at `https://dashboard.example.com/settings/api`.
</Callout>

## Setting Up Webhooks

Webhooks enable real-time updates from Clarity OPS to your services. Configure them to trigger on events like order creation or inventory changes.

<Steps>
  <Step title="Generate Webhook URL" icon="link">
    In your dashboard, navigate to Settings > Webhooks. Create a new webhook and copy the generated URL.
  </Step>
  <Step title="Select Events" icon="bell">
    Choose events such as `order.created`, `inventory.updated`, or `product.sync`.
  </Step>
  <Step title="Verify Endpoint" icon="check-circle">
    Test the webhook by sending a sample payload. Ensure your endpoint responds with HTTP 200.
  </Step>
</Steps>

Here is a sample webhook payload for an order event:

<CodeGroup tabs="JSON">
  ```json
  {
    "event": "order.created",
    "data": {
      "id": "ord_123abc",
      "supplier": "Acme Corp",
      "items": [
        {
          "product_id": "prod_456def",
          "quantity": 100,
          "price": 29.99
        }
      ],
      "total": 2999
    },
    "timestamp": "2024-01-15T10:30:00Z"
  }
  ```
</CodeGroup>

## API Access for Custom Connections

Use the Clarity OPS REST API for programmatic access. Authenticate requests with your API key.

<ParamField header="Authorization" param-type="string" required="true">
  Bearer `{YOUR_API_KEY}`
</ParamField>

<ParamField query="supplier_id" param-type="string" required="false">
  Filter products by supplier.
</ParamField>

Example: Fetch products via API.

<Request tabs="cURL,JavaScript">
  ```bash
  curl -X GET "https://api.example.com/v1/products" \
    -H "Authorization: Bearer YOUR_API_KEY"
  ```

  ```javascript
  const response = await fetch('https://api.example.com/v1/products', {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY'
    }
  });
  const products = await response.json();
  ```
</Request>

<Response tabs="200">
  ```json
  {
    "products": [
      {
        "id": "prod_456def",
        "name": "Widget Pro",
        "price": 29.99,
        "stock": 500
      }
    ]
  }
  ```
</Response>

## E-commerce Platform Syncing

Sync inventory and orders with popular platforms.

<Tabs>
  <Tab title="Shopify" icon="shopping-cart">
    Use OAuth to connect your Shopify store. Clarity OPS pushes inventory updates every 15 minutes.

    <CodeGroup tabs="Node.js,Python">
      ```javascript
      // Shopify product sync
      await fetch('https://api.example.com/v1/sync/shopify', {
        method: 'POST',
        headers: { 'Authorization': 'Bearer YOUR_API_KEY' },
        body: JSON.stringify({ shop: 'your-shop.myshopify.com' })
      });
      ```

      ```python
      import requests
      response = requests.post(
        'https://api.example.com/v1/sync/shopify',
        headers={'Authorization': 'Bearer YOUR_API_KEY'},
        json={'shop': 'your-shop.myshopify.com'}
      )
      ```
    </CodeGroup>
  </Tab>
  <Tab title="WooCommerce" icon="wordpress">
    Configure webhooks in WooCommerce to pull orders into Clarity OPS.
  </Tab>
</Tabs>
