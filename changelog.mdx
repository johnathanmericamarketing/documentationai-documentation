## Migration Notes

Update your integration code:

<CodeGroup tabs="JavaScript,Python">
  ```javascript
  // Old API key auth
  const response = await fetch('https://api.example.com/orders', {
    headers: { 'X-API-Key': 'YOUR_API_KEY' }
  });

  // New JWT auth
  const token = await getJWTToken();
  const response = await fetch('https://api.example.com/orders', {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  ```
  ```python
  import requests

  # Old API key auth
  response = requests.get('https://api.example.com/orders', headers={'X-API-Key': 'YOUR_API_KEY'})

  # New JWT auth
  token = get_jwt_token()
  response = requests.get('https://api.example.com/orders', headers={'Authorization': f'Bearer {token}'})
  ```
</CodeGroup>

</Update>
